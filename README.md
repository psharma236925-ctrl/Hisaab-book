## 💡 About The Project

Say goodbye to confusing paper ledgers and scattered notes! **Hisaab Book** is a lightweight, frontend-only web application designed to track personal micro-finances with absolute ease. Whether you are managing daily expenses, tracking money lent to friends, or keeping a record of money you owe, Hisaab Book handles it all in a sleek, native-app-like interface.

Built focusing on **Privacy and Speed**, it runs completely in your browser and stores data locally. No servers, no sign-ups, and zero data tracking.

### ✨ Standout Features

- **💸 Dual Ledger System:** Effortlessly toggle between **"Maine Diye"** (Money Lent) and **"Maine Liye"** (Money Borrowed) with automatic total calculations.
- **📲 Dynamic UPI QR Generation:** Set up your UPI ID once, and instantly generate a dynamic QR code for the exact pending amount. Get paid faster and smarter!
- **🔔 Smart WhatsApp Reminders:** Send auto-formatted WhatsApp messages reminding people of their dues, complete with your UPI details, in a single click.
- **📸 Receipt & Proof Attachments:** Attach screenshots or photos of transactions. The app includes an under-the-hood auto-compression algorithm to prevent browser storage bloat.
- **📊 Interactive Passbook Timeline:** View a beautiful, chronological timeline for every individual, detailing exactly when money was given or received.
- **🔒 100% Offline & Private:** Powered by HTML5 `localStorage`. Your financial data never leaves your device.
- **📱 PWA-Ready UI:** Crafted meticulously with Tailwind CSS to provide a seamless mobile application feel directly within a web browser.

## 🛠️ Tech Stack

This project demonstrates clean architecture using purely vanilla web technologies without the overhead of heavy frameworks.

*   **Markup:** HTML5
*   **Styling:** Tailwind CSS (via CDN for rapid prototyping)
*   **Logic & State Management:** Vanilla JavaScript (ES6+)
*   **Icons:** FontAwesome 6
*   **QR Generation:** GoQR API
